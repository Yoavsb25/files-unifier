Before

A folder of scans with inconsistent names. Someone opens each one, finds its row in the spreadsheet, then merges and renames it by hand. It takes hours, and mistakes slip through.

After

Pick the spreadsheet, pick the folder, click merge. You get clean files named per row, plus a report flagging anything that needs a human.

How it works

Three steps, no training required

1

Load your manifest

A CSV or Excel file with one row per output document. Your existing spreadsheet usually works as-is.

2

Point to your PDFs

Files are matched to rows by serial number or document ID, even when the filenames are messy.

3

Merge and review

Merged PDFs land in your output folder, alongside a summary report covering every row.

Capabilities

Built for accuracy, not just speed

Smart matching

Confidence-scored matching that flags ambiguous files instead of guessing.

Custom naming

Name each output file from any column in your spreadsheet.

Large batches

Audit report

Every run ends with a report. Every row is accounted for, merged, skipped or failed, so nothing goes missing quietly.
